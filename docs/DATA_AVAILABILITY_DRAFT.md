# Data availability text for author confirmation

Aggregate data underlying the reported tables, together with a data dictionary,
Python analysis code, and reproducibility instructions, are available at
<https://github.com/lianjiabian/Respiratory_Pathogen_Dynamics>. Individual-level
laboratory records are not publicly deposited because exact dates, detailed
ages, sex, longitudinal identifiers, and pathogen-result combinations could
permit re-identification. Requests for controlled access should be submitted to
**[institutional data-access body]** at **[institutional contact]** and are
subject to institutional and ethics approval, applicable data-protection
requirements, and a data-use agreement.

The bracketed institutional body and contact must be confirmed by the authors.
For long-term citation, archive a tagged GitHub release in a repository that
issues a DOI and insert that DOI before final publication.
